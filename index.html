Cómo desplegar en GitHub Pages (2 minutos)
  1. Crea un repositorio nuevo en GitHub (p. ej. kalm).
  2. Sube este archivo renombrado como index.html.
  3. En Settings → Pages, elige la rama main y la carpeta / (root), y guarda.

No requiere servidor ni configuración adicional.

Proxy propio en Cloudflare Workers (gratis, 5 min, 100% fiable)

Los proxies CORS públicos están saturados o cerrados (error 429/401). Con un Worker gratis propio el modo Proxy funciona siempre:

  1. Entra en workers.cloudflare.com → Create Worker.
  2. Pega este código y pulsa Deploy:
export default {
  async fetch(req) {
    const u = new URL(req.url).searchParams.get('url');
    if (!u) return new Response('falta ?url=', {status:400});
    const r = await fetch(u, {redirect:'follow',
      headers:{'User-Agent':'Mozilla/5.0'}});
    const h = new Headers(r.headers);
    h.set('Access-Control-Allow-Origin','*');
    h.delete('content-security-policy');
    h.delete('x-frame-options');
    return new Response(r.body, {status:r.status, headers:h});
  }
}
  1. Copia la URL del worker (https://tuworker.tucuenta.workers.dev/) y pégala arriba en «Proxy personalizado».
Acerca de KALM

KALM v4.6 es un «navegador dentro del navegador» sin Service Worker. v4.6 cambia la estrategia de proxy: el HTML se descarga por el proxy (tu Worker propio o, en su defecto, relays públicos) y se reescribe con un <base href> apuntando al sitio original; las imágenes, CSS, JS y fuentes se cargan directamente del origen, sin pasar por proxies intermedios. Esto elimina los fallos en cascada cuando un relay público devolvía 429 o HTML de error como si fuera una imagen.

Modo Directo: el sitio carga nativo en el marco. Es la única vía para los .cu (los relays extranjeros reciben geo-bloqueo del origen cubano). Modo Proxy: el HTML se descarga por el proxy y se muestra aislado con sandbox. Con un Worker propio configurado, los sitios internacionales van automáticamente por proxy porque la mayoría envían X-Frame-Options y no pueden enmarcarse de forma nativa.

Límites conocidos del enfoque srcdoc: el JS del sitio que depende de location.href verá about:srcdoc, no la URL real. Los sitios .cu en http:// no se pueden enmarcar desde un KALM servido por https:// (contenido mixto): usa el botón «Guardar KALM en tu equipo» para abrirlo en local. El 403 de UCLV es rechazo del servidor a tu red/IP: cambia de red, renueva IP, reintenta o espera.
