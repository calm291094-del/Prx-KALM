Cómo desplegar en GitHub Pages (2 minutos)
  1. Crea un repositorio nuevo en GitHub (p. ej. kalm).
  2. Sube este archivo renombrado como index.html.
  3. En Settings → Pages, elige la rama main y la carpeta / (root), y guarda.
  4. En 1-2 minutos estará en https://tuusuario.github.io/kalm/.

No requiere servidor ni configuración adicional.

Proxy propio en Cloudflare Workers (gratis, 5 min, 100% fiable)

Los proxies CORS públicos están saturados o cerrados (error 429/401). Con un Worker gratis propio el modo Proxy funciona siempre:

  1. Entra en workers.cloudflare.com → Create Worker.
  2. Pega este código y pulsa Deploy:
export default {
  async fetch(req) {
    const u = new URL(req.url).searchParams.get('url');
    if (!u) return new Response('falta ?url=', {status:400});
    const r = await fetch(u, {redirect:'follow',
      headers:{'User-Agent':'Mozilla/5.0'}});
    const h = new Headers(r.headers);
    h.set('Access-Control-Allow-Origin','*');
    h.delete('content-security-policy');
    h.delete('x-frame-options');
    return new Response(r.body, {status:r.status, headers:h});
  }
}
  1. Copia la URL del worker (https://tuworker.tucuenta.workers.dev/) y pégala arriba en «Proxy personalizado».
Acerca de KALM

KALM es un «navegador dentro del navegador»: carga páginas en un marco interno sin Service Worker. Modo Directo: el sitio se carga nativo en el marco (ideal para visuales.uclv.edu.cu desde Cuba, cero intermediarios). Modo Proxy: el HTML se descarga, se reescriben las URLs y se muestra aislado (sandbox). Incluye descargas comprimidas en ZIP con numeración automática desde 00001. Inspirado en la arquitectura GUST (libcurl.js + túnel WISP opcional).
